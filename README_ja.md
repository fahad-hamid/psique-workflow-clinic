# Sesión — メンタルヘルス診療オーケストレーションプラットフォーム

**Sesión**は、アルゼンチンの心理クリニックや個人開業医向けに特別に設計されたSaaSオペレーティングシステムであり、臨床業務、管理業務、コミュニケーションワークフローを1つのインテリジェントな環境に統合しています。このリポジトリには、予約スケジュールの調整、WhatsAppを介した自動メッセージ送信、請求処理、安全なビデオ診察、そしてClaude Opus 4.6およびSonnet 4.6モデルを活用した統合AI層を制御するコアなオーケストレーションエンジンが含まれています。

## 概要

現代の心理療法施設の運営には、単なるカレンダーや電話だけでは不十分です。アルゼンチンの臨床家たちは、AFIP規格に準拠した電子請求から、患者との主要なコミュニケーション手段として広く利用されているWhatsAppに至るまで、独自の規制上の要件や言語的・文化的課題に直面しています。Sesiónはこうした具体的なニーズに応えるために初めから体系的に設計されており、複雑な業務処理をシンプルで直感的なインターフェースに変換し、臨床家が最も重要なこと、つまり患者ケアに集中できる環境を提供します。

このプラットフォームのオーケストレーション層はデジタル神経系として機能し、スケジューリング、請求、コミュニケーション、AIモジュール間でデータを極めて低い遅延と最高水準の信頼性をもって転送します。臨床家が5つもの独立したツールを使い分ける必要があるのとは異なり、Sesiónは統一されたコックピットを提供し、最初の問い合わせから最終的な請求書発行に至るまで、すべての患者とのやり取りが一貫性があり監査可能なパイプラインを通じて処理されます。

## コア機能

### 📅 スマートなアジェンダ管理

スケジューリングエンジンは、制約ベースの推論を用いて、複数の担当医師、部屋、およびセッションタイプ（対面、オンライン、評価）間での予約割り当てを最適化します。また、アルゼンチンで一般的なセッション時間（個人セラピーは通常45分、カップルや家族向けは90分）を尊重しつつ、カスタマイズ設定も可能です。アジェンダは自動的にスケジュールの衝突を検出し、患者の履歴に基づいて代替の時間帯を提案するほか、Google CalendarやOutlookと双方向同期によって連携します。

主な機能は以下の通りです：
- 定期的なセッションパターンの認識（週1回、2週間に1回、月1回）
- 自動優先順位付けを伴う待機リスト管理
- 猶予期間の設定を含む緊急キャンセル対応
- 複数施術者の空き状況マトリックス
- ルームおよびリソースの割り当てロジック

### 💬 WhatsApp自動化スイート

アルゼンチンのモバイル優先のコミュニケーション文化では、単なるメッセージ転送を超えたWhatsApp連携が求められます。SesiónのWhatsApp自動化層は、患者とのコミュニケーションライフサイクル全体を管理するステートマシンアーキテクチャに基づいて構築されています。

- セッションの24時間前および2時間前に送信される**予約リマインダー**  
- ワンタップで返信を解析できる**セッション確認依頼**  
- 密碼化された回答形式の**セッション後満足度アンケート**  
- 患者のWhatsApp受信箱に直接送信される**請求書**  
- **危機対応プロトコル** — 患者が苦痛を示すキーワードを含むメッセージを送信した場合、システムが即座に担当医師に通知する

すべてのWhatsAppでのやり取りは、アルゼンチンのデータ保護法（法律第25.326号）を遵守しており、各やり取りの場面においてオプトアウト機能が備わっています。

### 💳 電子請求書発行（AFIP準拠）

アルゼンチンの税務当局（AFIP）は、すべての専門サービスにおいて電子請求書の提出を義務付けています。Sesiónの請求モジュールは、開業医の税務区分に応じて、規定に完全に準拠したA型、B型、C型、M型の請求書を自動的に生成します。このシステムは：

- セッションを正しい税務領収書と自動的に関連付ける  
- 完整な税務監査記録を維持する  
- 納税申告用の月次要約書（Ganancias、Monotributo、Responsable Inscripto）を生成する  
- 複数の支払い方法（送金、Mercado Pago、現金、カード）に対応する  
- 各州ごとのIIBB（総所得）源泉徴収額を計算する

### 🎥 安全なビデオ通話

ビデオ相談機能は、アルゼンチンの家庭でよく見られる帯域幅の制約に合わせて設計された、エンドツーエンド暗号化を備えたWebRTCベースのエンジンによって動作します。このシステムはリアルタイムのネットワーク測定値に基づいてビットレートと解像度を動的に調整するため、4G携帯回線を使用していても安定した会話が可能です。主な機能は以下の通りです：

- 専門家が受付を制御するバーチャル待合室  
- 心理評価ツール用の画面共有機能  
- セッション録画機能（二重同意確認付き）  
- 家庭環境に最適化されたノイズ抑制機能  
- 緊急時のセッション引き継ぎ機能

## 技術アーキテクチャ

Sesiónはコンテナ化されたインフラ上に構築されたマイクロサービスエコシステムとして機能し、アジェンダ、WhatsApp、請求、ビデオ通話、AIといった各ドメインが独立してスケーリング可能なサービスとして動作します。このリポジトリ内にあるオーケストレーション層が、同期処理ではgRPCを、イベント駆動型のワークフローではApache Kafkaを利用して、サービス間の通信を管理しています。

データ層では複数のストレージ技術を組み合わせた永続化戦略が採用されています：
- 関係型データ（患者情報、予約記録、請求書）には**PostgreSQL**を使用
- セッションキャッシュやリアルタイムのプレゼンス情報には**Redis**を使用
- 患者記録や臨床ノート全体の全文検索には**Elasticsearch**を使用
- 同意書や評価結果といった暗号化された文書の保存には**MinIO**を使用

## AIオーケストレーション：Claude Opus 4.6 + Sonnet 4.6

Sesiónは、専門的な認知タスクを処理するために2つの異なるAnthropicモデルを統合しており、プロンプトの複雑さやレイテンシ要件に応じて賢くタスクを割り当てるモデルルーターによって制御されています。

**Claude Opus 4.6**は、臨床記録の要約作成、治療効果の予測、さらには何百回ものセッション分にわたる患者歴史の長文コンテキスト分析といった高度な認知処理を担います。このモデルは、地域の文化的背景や表現習慣、地域特有の心理学的手法を理解するために、厳格なデータガバナンスポリシーのもとで匿名化されたアルゼンチンの精神保健データを用いて微調整が行われています。

**Sonnet 4.6**はリアルタイムの対話型インターフェースとして機能し、アプリ内のチャットアシスタントを動作させることで、医療従事者が患者情報を迅速に検索したり、臨床記録を作成したり、保険基準に準拠したセッションレポートを生成したりできるようにします。Sonnetの数秒単位の応答速度により、ライブセッション中のインタラクティブな利用にも適しています。

オーケストレーション層には以下の機能が含まれます：
- GDPRおよび法律第25.326号の要件を満たすコンテキストウィンドウ機能を備えたプロンプトテンプレートエンジン
- モデルのフォールバックロジック（Opus → Sonnet → 失敗時のキャッシュされた応答）
- 各臨床医別の利用状況追跡とコスト算出
- すべてのAI支援による臨床的判断に関する監査ログ

## 患者の経過マッピング

Sesiónは、設定可能なパイプラインステージ——初回接触 → 受け入れ → 実際のセッション → 終了 → フォローアップ——を通じて、各患者の経過を可視化します。このパイプライン方式により、臨床従事者は以下のことができます：

- 一定回数のセッションを経ても再来していない患者を特定する  
- 治療終了後に自動的なフォローアップ手順を実行する  
- 出席パターンに基づきリスクの高い患者に対する警告を発行する  
- 平均治療期間および中止率を測定する

## コンプライアンスとデータ主権

すべての患者データはアルゼンチンの管轄範囲内に留まります。Sesiónのインフラストラクチャはブエノスアイレスの（第III層データセンター）に設置されており、以下の規制を遵守しています：

- **法律第25.326号**（個人情報保護法）
- **法律第26.529号**（患者の権利に関する法律）
- **AFIP一般決議第4291号**（電子請求に関する規定）
- **心理学者協会**の倫理的実践ガイドライン

## セキュリティ体制

セキュリティは後付けの対策ではなく、基盤となる層として設計されています。

- 全ての患者と医師間のコミュニケーション（ビデオ通話、チャット、共有ファイル）における**エンドツーエンド暗号化**
- **ゼロ知識アーキテクチャ** — Sesiónは診療記録やセッション内容にアクセスできない
- 医師、アシスタント、管理者といった各役割ごとに詳細な権限を設定可能な**RBAC**（役割ベースのアクセス制御）
- 活動が15分間ない場合の**セッションタイムアウト**および自動ログアウト機能
- すべてのアカウントアクセスにおける**2FAの必須適用**
- アルゼンチンの独立系セキュリティ企業による**四半期ごとのペネトレーションテスト**

## ローカライゼーションと多言語サポート

Sesiónのメインインターフェースはアルゼンチンスペイン語（es-AR）であるものの、このプラットフォームでは以下の言語にも対応しています：

- スペイン語の各地域方言（es-ES、es-MX、es-CL）に対応したインターフェースの完全な翻訳
- 海外居住者向けのクリニック向けに英語およびポルトガル語（pt-BR）による対応
- ページを再読み込みせずに動的にロケールを切り替える機能
- 数値の書式設定（小数点の使用可否）
- アルゼンチンの慣習に合わせた日付・時間の表記形式（DD/MM/YYYY、24時間表記）

## APIおよび統合フレームワーク

Sesiónは、カスタムな連携機能を構築したいクリニック向けに、詳細なドキュメントが用意されたRESTful APIを提供しています。

- 患者管理のCRUD操作
- 予約のスケジューリングおよび変更
- 請求記録の取得
- WhatsAppメッセージ履歴のエクスポート
- AIを活用した診療記録の作成

Webhookのサポートにより、予約の作成、キャンセル、請求書の生成、およびAI分析の完了に関するリアルタイム通知を受け取ることができます。レート制限により、すべての利用者間で公平にリソースが配分されます。

## レスポンシブなUIデザインの考え方

ユーザーインターフェースは情報量の階層構造に従っており、医療従事者はログイン時に最も重要なデータ（予定されている診察、未読メッセージ、期限の近い請求書）をすぐに確認でき、必要に応じて詳細な表示へと掘り下げることができます。デザインシステム：

- デスクトップブラウザ、タブレット、スマートフォンのいずれでもシームレスに動作します  
- モバイルを利用する医療従事者向けにタッチ操作に最適化されたインタラクションを実装しています  
- 環境光の状況に関わらず読みやすくするため、高コントラストモードを提供しています  
- ユーザーの好みに合わせてダッシュボードのレイアウトをカスタマイズできます
