# Sesión — 心理健康诊疗流程编排平台

**Sesión** 是专为阿根廷的心理咨询诊所及独立从业者打造的 SaaS 操作系统，它将临床、行政及沟通等各类工作流程整合到一个智能化的统一环境中。该仓库中包含了核心的编排引擎，可用于协调预约安排、自动发送 WhatsApp 消息、处理账单与发票、实现安全视频咨询，同时还集成了由 Claude Opus 4.6 与 Sonnet 4.6 模型驱动的 AI 功能层。

## 概览

现代心理诊疗管理需要的远不止日历和电话而已。阿根廷的从业者面临着独特的监管、语言及文化要求——从需符合AFIP标准的电子发票制度，到WhatsApp作为主要患者沟通渠道的普遍使用。Sesión从架构设计之初就专为满足这些特定需求而打造，它将复杂的运营流程转化为简洁直观的用户界面，让临床医生能够专注于最重要的事情：为患者提供护理服务。

该平台的调度层犹如数字神经系统，能够以极低的延迟和最高的可靠性在日程安排、计费、沟通以及人工智能模块之间传输数据。Sesión无需让从业者同时操作五种相互独立的工具，而是提供了一个统一的控制中心，从首次咨询到最终开具发票的每一次患者互动，都能在一条连贯且可追溯的流程中完成。

## 核心功能

### 📅 智能日程管理

调度引擎通过基于约束的推理机制，优化多名治疗师、不同房间以及各类会话类型（面诊、视频咨询、评估）之间的预约分配。它在遵循阿根廷常见的会话时长标准（个体心理治疗通常为45分钟，夫妻或家庭治疗为90分钟）的同时，也支持自定义配置。该系统能自动检测日程冲突，根据患者历史记录推荐替代时间，并通过双向同步功能与Google日历及Outlook实现集成。

主要功能包括：
- 周期性诊疗模式识别（每周、每两周、每月）
- 带自动优先级排序的等候名单管理
- 带宽限期要求的紧急取消处理机制
- 多位医师可用性矩阵
- 房间及资源分配逻辑

### 💬 WhatsApp自动化套件

阿根廷以移动端优先的沟通文化使得需要一种超越简单消息转发的WhatsApp集成方案。Sesión的WhatsApp自动化层基于状态机架构构建，可管理完整的患者沟通全流程：

- 在疗程开始前24小时及2小时发送**预约提醒**
- 支持一键回复解析的**疗程确认请求**
- 包含加密回复功能的**疗程后满意度调查**
- 直接发送至患者WhatsApp收件箱的**账单**
- **危机升级机制**——若患者发送表明处于困境的关键词，系统会立即向医生发出警报

所有通过WhatsApp进行的沟通均符合阿根廷数据保护法律（第25.326号法律），且在每个交互环节都设有退出机制。

### 💳 电子发票开具（符合AFIP法规要求）

阿根廷税务机构（AFIP）要求所有专业服务都必须使用电子发票。Sesión的计费模块会根据从业者的税务类别，自动生成完全符合规定的A、B、C及M类发票。该系统：

- 自动将诊疗记录与正确的税务凭证关联  
- 完整保留所有税务审计轨迹  
- 生成用于纳税申报的月度汇总报表（Ganancias、Monotributo、Responsable Inscripto）  
- 支持多种支付方式（银行转账、Mercado Pago、现金、银行卡）  
- 按省份计算IIBB（总收入）预扣税额

### 🎥 安全的视频通话功能

视频咨询功能依托基于WebRTC的引擎实现，具备端到端加密技术，并针对阿根廷家庭常见的带宽限制进行了优化。该系统会根据实时网络检测动态调整比特率和分辨率，从而即便在4G移动网络环境下也能保证通话稳定。其功能包括：

- 由执业医生控制准入的虚拟等候室  
- 用于心理评估工具的屏幕共享功能  
- 会议录制功能（需经过双重同意验证）  
- 针对家庭环境优化的噪音抑制技术  
- 紧急接管会议会话的功能

## 技术架构

“Sesión”是一个构建在容器化基础设施上的微服务生态系统，各个功能模块（日程管理、WhatsApp沟通、账单处理、视频通话、AI功能）均为可独立扩展的服务。位于该代码库中的编排层通过gRPC实现同步操作时的服务间通信，同时借助Apache Kafka处理基于事件驱动的工作流。

数据层采用了多种存储技术相结合的持久化策略：
- **PostgreSQL**用于存储关系型数据（患者信息、预约记录、账单等）
- **Redis**用于会话缓存及实时在线状态检测
- **Elasticsearch**用于对患者记录和临床笔记进行全文搜索
- **MinIO**用于加密存储文档（同意书、评估结果等）

## AI编排：Claude Opus 4.6 + Sonnet 4.6

Sesión集成了两种不同的Anthropic模型，用于处理各类专业的认知任务，而模型路由器则会根据提示的复杂度及延迟要求智能地分配任务给相应的模型。

**Claude Opus 4.6**则负责处理复杂的认知任务：包括临床笔记总结、治疗效果预测，以及分析数百次会话中的患者病史长文本。该模型在经过匿名处理的阿根廷心理健康数据上进行了微调（并遵循严格的数据管理规范），以此理解当地的文化背景、惯用表达以及区域性的心理学框架。

**Sonnet 4.6**则作为实时对话界面，为应用内的聊天助手提供支持，帮助从业者快速调取患者信息、撰写临床记录或生成符合保险要求的会诊报告。Sonnet亚秒级的响应速度使其非常适合在实时会诊过程中进行互动使用。

该协调层包含以下功能：
- 具备GDPR及第25.326号法律合规要求的上下文窗口管理的提示词模板引擎
- 模型降级逻辑（在模型出错时依次切换为Opus、Sonnet，最终使用缓存响应）
- 针对每位从业者的使用情况追踪与成本分摊功能
- 所有人工智能辅助做出的临床决策的审计日志

## 患者诊疗流程可视化

Sesión通过可配置的流程阶段来可视化每位患者的诊疗历程：初次接触→入院→治疗进行中→结束→随访。这种流程化方式让临床医生能够：

- 识别在完成一定次数的诊疗后仍未复诊的患者  
- 在治疗结束后触发自动的随访流程  
- 根据就诊规律生成高风险患者警报  
- 统计平均治疗时长及患者流失率

## 合规性与数据主权

所有患者数据均保留在阿根廷的管辖范围内。Sesión的基础设施部署在布宜诺斯艾利斯的第三级数据中心中，并符合以下标准：

- **第25.326号法律**（个人数据保护法）
- **第26.529号法律**（患者权利法）
- **AFIP第4291号总决议**（电子发票规定）
- **心理学家协会**伦理实践指南

## 安全保障机制

安全机制被设计为底层基础，而非事后才考虑的附加要素：

- 对所有患者与医生的沟通内容（视频、聊天、共享文件）实施**端到端加密**
- **零知识架构**——Sesión无法访问临床记录或会话内容
- 基于角色的访问控制（RBAC），为医生、助理及管理员角色设置精细的权限划分
- 设置**会话超时机制**，在15分钟无操作后自动登出
- 要求所有账户访问都必须进行**双重身份验证**
- 由阿根廷的独立安全公司每季度进行**渗透测试**

## 本地化与多语言支持

尽管 Sesión 的主要界面使用阿根廷西班牙语（es-AR），但该平台还支持：

- 支持多种西班牙语方言的界面完整翻译（es-ES、es-MX、es-CL）
- 为服务外籍人士群体的诊所提供英语及葡萄牙语（pt-BR）版本
- 无需重新加载页面即可动态切换区域设置
- 数字格式设置（小数点与逗号的使用）
- 符合阿根廷习惯的日期和时间格式（DD/MM/YYYY、24小时制）

## API与集成框架

对于希望构建自定义集成功能的诊所，Sesión 提供了带有完整文档的 RESTful API：

- 患者管理相关的创建、读取、更新、删除操作
- 预约时间的安排与修改
- 账单记录查询
- WhatsApp消息历史导出
- 人工智能辅助的病历生成

Webhook 支持可针对预约创建、取消、发票生成以及 AI 分析完成等操作发送实时通知。速率限制机制则能确保所有用户公平地使用资源。

## 响应式用户界面设计理念

用户界面采用了信息密度分层设计——医生登录后即可看到最关键的数据（即将开始的诊疗、待处理消息、到期账单），同时还可根据需要深入查看详细信息。该设计系统包括：

- 能在桌面浏览器、平板电脑及智能手机上无缝运行  
- 为移动端从业者提供针对触摸操作的优化交互体验  
- 支持高对比度模式，以便在各种光照条件下都能清晰阅读  
- 允许根据用户偏好自定义控制面板布局
